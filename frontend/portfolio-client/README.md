# Joseph Sotomil Portfolio

Static React portfolio built with Vite and local data from `src/data/mockPortfolioData.js`.

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Vercel Deployment

Deploy this folder as a frontend-only Vercel project:

- Root directory: `frontend/portfolio-client`
- Framework preset: `Vite`
- Build command: `npm run build`
- Output directory: `dist`

No backend service, database, Prisma setup, Render service, Supabase project, or Vercel environment variables are required.
